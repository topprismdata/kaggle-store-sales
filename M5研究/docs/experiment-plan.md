# M5研究 — E1–E4 预注册实验计划（草案）

状态：**DESIGNED / NOT RUN**。

## E1：官方预测评分复现

**研究问题**：能否正确复现数据层级、时间切分、WRMSSE 和 WSPL？  
**输入**：M5 官方数据、官方基线/合法获取的预测文件。  
**主要检查**：层级数量、权重求和、尺度项、稀疏序列、预测格式、复算结果与官方已知对照。  
**通过门槛**：复算在事先记录的数值容差内一致；容差依据官方脚本与浮点精度确定，不事后调整。

## E2：时间外与分层稳健性

**研究问题**：获胜方法的优势是否依赖某个测试窗口或特定聚合层级？  
**方法**：多个按时间向前滚动的冻结窗口，同预算对照简单统计与全局模型。  
**指标**：每层 WRMSSE、方法排名、跨窗口变异、序列分组表现。  
**判定**：允许“部分层级胜出、部分层级失败”，不得将平均优势泛化为各层都胜出。

## E3：概率预测可靠性

**研究问题**：哪种方法在 M5 九分位点评分与尾部风险上更可靠？  
**候选**：经验分位数、Quantile LightGBM、负二项计数模型、样本轨迹模型。  
**指标**：WSPL、Pinball、分位校准、锐度、分位数交叉率、尾部覆盖与时间稳定性。  
**防泄漏**：分位数后校准与模型组合只用独立历史窗口。

## E4：库存策略价值模拟

**研究问题**：预测评分与库存损失排名是否一致？在何种政策和成本条件下反转？  
**设计**：固定预测输出，变更库存策略；固定策略，变更预测方法。共享成本参数、补货提前期、需求情景与随机种子。  
**指标**：平均成本、CVaR 或极端损失、服务水平、单位库存成本、计算成本。  
**证据声明**：全部结果标记 `SIMULATED`，不得写成真实企业利润。

## E5：联合概率结构是否创造增量决策价值

研究边际分位数是否足以支持库存决策。先运行 `experiments/joint_dependence_demo.py` 作为理论正/负对照，再在真实 M5 预测起点上比较边际分位数、独立抽样、残差 Bootstrap 和概率协调路径。评价共享库存池的期望短缺、超容量概率与尾部成本，同时设置固定分散配额的负对照。具体假设、评分、门槛和失败判据见 [联合概率预测专题](joint-probabilistic-forecasting.md)。

**关键限定**：固定订货量且完全可加的期望损失不一定需要联合分布；共享容量、联合机会约束、动态调拨及整体 CVaR 才是依赖结构可能产生价值的决策场景。
