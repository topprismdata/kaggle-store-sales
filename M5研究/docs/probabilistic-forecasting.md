# 概率预测专题：从 M5 九个分位数到决策分布

## 1. 预测对象是什么？

点预测输出一个数 `ŷ`；概率预测尝试刻画未来结果 `Y` 在预测时间点已知信息 `X_t` 下的条件分布：

```math
P(Y_{t+1:t+h} \mid X_{\le t})
```

**条件分位数**：`q_τ(X)` 满足预测分布中大致 `τ` 比例的结果低于此值。P90=500 不代表销量有 90% 概率恰好等于 500；在正确校准的预测下，约 90% 的未来结果不高于 500。

实际零售销量的分布与无供给约束的潜在需求分布不同。缺货会截断观测销售；不能未经修正直接将销售分位数解释成需求分位数。

## 2. M5 Uncertainty 的具体输出

官方九个水平为：
`{0.005, 0.025, 0.165, 0.250, 0.500, 0.750, 0.835, 0.975, 0.995}`。

相应组成 99%、95%、67%、50% 的中心预测区间与中位数。它们是有限的分位数摘要，**不是完整的联合概率分布**。

M5 预测对象有 12 个层级、42,840 条聚合序列，采用加权尺度化 Pinball Loss (WSPL) 比较不同分位数的质量。

## 3. 必须区分四件事

- **Calibration（校准）**：预测 P90 在大量对应观测中，实际有多少百分比低于预测？总体覆盖率可能掩盖商品类别、时段和尾部失效。
- **Sharpness（锐度）**：在校准成立的前提下，预测区间是否尽可能收窄？只输出过宽区间不能算高质量。
- **Scoring（适当评分）**：Pinball Loss 对分位数具有一致性；综合评分不能只看某个漂亮的覆盖率。
- **Dependence（联合依赖）**：跨门店、跨商品、跨时间的相关性决定总量尾部和库存同时短缺风险。

Pinball Loss：

```text
L_τ(y, q) = (τ - 1{y < q}) (y - q)
```

在 `τ=0.9` 时低估通常比同幅度高估惩罚更大，但该统计非对称并不天然等于经营上的缺货/积压成本比率。

## 4. 分位数不能随意相加

两区域需求完全反向：各以 50% 概率出现 `(A=100,B=0)` 或 `(A=0,B=100)`。

则 `P90(A)=100`，`P90(B)=100`，但总和始终为 100，因此 `P90(A+B)=100`，并不等于 200。

联合需求的正确处理需要一组依赖结构一致的情景路径、概率层级协调或适当的联合模型。独立训练多个 P90 不能自动解决这一问题。

## 5. 候选方法与基线

| 方法 | 研究作用 | 关键风险 |
|---|---|---|
| 历史经验分位数 | 低成本强基线 | 分组样本少、随时间变化 |
| Quantile LightGBM | 多序列条件分位数预测 | 分位数交叉、条件覆盖不足 |
| 负二项 / 计数分布模型 | 适应离散计数、过度离散 | 分布假设错误 |
| 状态空间 + Monte Carlo | 可形成时间一致的样本轨迹 | 跨序列依赖仍需建模与检验 |
| 集成/后校准 | 提升稳健性 | 不可使用测试标签选规则 |

要单独检查零销量比例、非零销量强度、右尾极端值和完整预测跨度。

## 6. 正式验收指标

1. 各分位点与加权 WSPL / Pinball；
2. 经验覆盖率（总体与分组）、条件校准图；
3. 预测区间宽度及 Weighted Interval Score；
4. 分位数单调性、非负整数约束；
5. 联合情景的相关性、聚合一致性和时间稳定性；
6. 固定库存政策下的成本/服务情景敏感性。
