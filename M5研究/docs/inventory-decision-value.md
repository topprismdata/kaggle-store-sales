# 预测精度与库存决策经济价值

## 1. 核心命题

“预测更准”不是“库存决策更好”的充分条件。经济结果取决于需求的不确定性、缺货/积压损失、策略约束、提前期、检查周期以及决策是否真正能够调整。

### 基础报童问题（教学模型）

假设单产品单周期需求 `D`，订货量 `q`，少备一件代价 `c_u`，多备一件代价 `c_o`：

```text
Loss(q, D) = c_u * max(D-q,0) + c_o * max(q-D,0)
q* = F_D^{-1}(c_u/(c_u+c_o))
```

这里的分位点由经济成本确定，并非“P90 永远最好”。多商品共享库存的优化必须加入联合情景和约束。

## 2. M5 后续论文的实证逻辑

- Spiliotis et al. (2021)：在 M5 销售序列上比较多种概率方法，结合库存指标、成本与计算时间评价。
- Theodorou et al. (2025)：比较 13 种预测方法以及不同库存策略、服务目标、补货提前期和检查周期，对比预测误差和库存成本。

**重要限定**：研究主要基于模拟政策，不等于沃尔玛或其他企业的真实增量利润。

## 3. 推荐的实验因子

| 因子 | 候选水平 |
|---|---|
| 预测 | 简单统计 / 全局树 / 经验分位数 / 计数模型 |
| 策略 | 固定规则 / order-up-to / 风险约束策略 |
| 单位缺货成本 | 低 / 中 / 高 |
| 单位持有成本 | 低 / 中 / 高 |
| 提前期 | 短 / 长 |
| 检查周期 | 高频 / 低频 |
| 需求类型 | Smooth / Intermittent / Lumpy / Erratic |

不同策略必须共享相同的成本假设与需求情景。通过全因子或预注册子集识别：哪种预测在什么条件下造成决策收益，及其失效边界。

## 4. 判断标准

- 预测改进带来的**增量**策略价值（固定优化器）；
- 优化器改变带来的**增量**策略价值（固定预测器）；
- 是否存在显著策略排名反转；
- 极端需求情景下是否出现不可接受的损失；
- 统计优势是否大于额外计算与执行成本。

## 5. 不应声称的结论

- “WRMSSE 下降 10% = 利润上升 10%”；
- “预测 90% 分位数能保证 90% 服务率”；
- “M5 数据能直接识别所有售罄后真实需求”；
- “仿真中的利润差等于真实因果收益”。
