# M5研究：任务定义、资料范围与核心判断

## 1. 为什么研究 M5

第五届 Makridakis Forecasting Competition（M5，2020）提供了规模化、具有层级结构的零售预测比较环境。研究的不仅是算法分数，还包括训练时间边界、模型稳定性、概率预测和预测—库存决策之间的关系。

核心问题依次是：

1. 能否在固定公开协议下预测销量？
2. 好的模型能否跨时间、商品及聚合层级保持优势？
3. 能否为需求的不确定性提供可靠的概率信息？
4. 在相同库存政策和资源约束下，该信息是否创造经济决策价值？

这四个问题彼此相关，但不能相互替代。

## 2. 原始竞赛：两个赛道

| 维度 | Accuracy | Uncertainty |
|---|---|---|
| 输出 | 未来 28 天销售点预测 | 28 天预测对象的九个分位数 |
| 主评分 | WRMSSE | Weighted Scaled Pinball Loss (WSPL) |
| 层级 | 12 个层级 | 12 个层级 |
| 聚合序列数 | 42,840 | 42,840 |
| 最细序列 | 30,490 条 item-store | 同上 |
| 目的 | 预测准确性 | 预测不确定性与分位数质量 |

三个州、十个门店、3,049 个商品，来自 Foods、Household、Hobbies 品类。公开数据包括日销售、日历（含特殊事件）和周售价等字段，商品—门店的销售不是无约束潜在需求。

### 12 层聚合结构

1 Total (1)；2 State (3)；3 Store (10)；4 Category (3)；5 Department (7)；6 State×Category (9)；7 State×Department (21)；8 Store×Category (30)；9 Store×Department (70)；10 Item (3,049)；11 Item×State (9,147)；12 Item×Store (30,490)。合计 42,840 条。

### 时间协议

初始训练至 d1913；d1914–1941 为公开验证的 28 天区间；d1942–1969 为私有测试的 28 天区间。实施复现时需按官方可见性规则处理日历、价格和目标字段，避免用未来销量构造特征。

## 3. 获奖方法给出的启示

Accuracy 冠军 DRFAM/ YJ_STU 的重要性在于：通过不同数据池训练分组 LightGBM，结合直接与递归预测，再进行简单平均。论文描述 220 个模型（10 个门店、30 个门店×品类、70 个门店×部门，再乘以两种策略）。

这不是“任意深度模型都会更好”的证据。是否适合新的预测问题，必须建立同预算强基线。

Uncertainty 的获奖方法也不是同一路线：梯度提升树、状态空间计数模型、经验分位数等都值得分别比较。排名依赖整体层级权重和所评价的分位点。

## 4. 科学结论与边界

- M5 官方预测冠军的结果是**在特定竞赛评分协议下的误差改善**，不是销售增长率。
- 后续滚动窗口研究挑战了单次排名稳定性，说明跨窗口复核必不可少。
- 2025 年库存绩效论文发现预测精度与库存成本的关系受到库存政策与经济成本影响，但该结论来自给定情景的**库存模拟**。
- M5 数据未提供完整历史库存、售罄时刻、未满足需求以及实际利润反事实，不能直接验证真实增量经营贡献。
- 从 M5 迁移到新品冷启动或其他商品类别，必须重新验证数据生成机制和预测时间边界。
