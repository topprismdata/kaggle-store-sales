# M5研究 · 第六阶段：从每日分位数到联合需求情景

**状态**：学术证据核对完成；理论反例可复算；真实 M5 数据实验尚未运行。  
**日期**：2026-11-09  
**核心原则**：先明确经济决策是否需要联合分布，再决定要不要建立依赖结构。

## 0. 本轮必须公开的更正

早期研究版 HTML Deck 曾将 M5 Uncertainty 描述成“28 天累计需求的九个分位数”。**该表述错误**。

官方提交格式为每个 `id` 对应 F1…F28 共 28 个日预测位置，每个层级系列预测九个分位点。一个提交阶段的数值规模为：

```text
42,840 series × 9 quantiles × 28 horizons = 10,795,680 cells
```

在验证与最终评估阶段各提交一次，不应把这些每日分位数解读为 28 天累计分布。来源：[Kaggle 官方 Evaluation 页面](https://www.kaggle.com/c/m5-forecasting-uncertainty) 和 [Makridakis et al. (2022)](https://doi.org/10.1016/j.ijforecast.2021.10.009)。

官方九个点是 `0.005, 0.025, 0.165, 0.25, 0.5, 0.75, 0.835, 0.975, 0.995`；**P90 不在官方九个点内**。用于经营的 P90 必须另行估计、经预注册方法插值并验证，不能直接说是 M5 官方提交值。

## 1. 四种不同的概率对象

| 对象 | 形式 | 能回答 | 不能回答 |
|---|---|---|---|
| 每日边际分位数 | `q_(i,t,tau)` | 一天某商品销量的尾部 | 28 日累计需求尾部、连续缺货风险 |
| 每序列累计量分布 | `F(sum_t D_(i,t))` | 周/月库存覆盖量 | 多区域同时缺货概率 |
| 联合情景路径 | `D^(s)_(i,t)` 与情景权重 | 组合缺货、跨店共振、库存池风险 | 不会自动恢复未观测潜在需求 |
| 潜在需求分布 | `P(D | 预测时可见信息)` | 缺货前需求及最优配置 | 若库存截断信息不充分则不可识别 |

原始 M5 数据主要提供*已实现销售量*；真实潜在需求、售罄后的损失销售和真实库存策略不是竞赛提供的完整证据。

## 2. 日分位数为什么不能直接求和？

`Q_tau(X+Y) != Q_tau(X)+Q_tau(Y)` 一般成立。

一个精确反例：

- 情景 A（同涨同跌）：`(X,Y)=(0,0)` 或 `(100,100)`，各概率 0.5。
- 情景 B（互相错开）：`(X,Y)=(0,100)` 或 `(100,0)`，各概率 0.5。
- 两组每个分量的所有边际分位数完全相同，包括 P90 = 100。
- A 的 `X+Y` 为 0 或 200，P90 = 200；
- B 的 `X+Y` 恒为 100，P90 = 100。

这可以表示不同地区、不同商品，也可以表示同一商品相邻两日。它证明仅有每日分位数、即使每个都准确，也**无法识别累计总量右尾**。

## 3. 更重要的限定：什么时候根本不需要联合分布？

当订货/配货 `q_i` 已固定，成本完全可按商品加总：

```text
L(q,D) = sum_i [cu_i * max(D_i - q_i, 0) + co_i * max(q_i - D_i, 0)]
```

则 `E[L]` 只由各 `D_i` 的**边际分布**决定。即使有 `sum_i q_i <= Q` 这样的确定性预算约束，求最小期望可加损失时仍不一定需要 Copula/联合路径。

**反之，联合分布通常对下列决策产生直接价值**：

1. 可实时共享的中心库存池，损失取决于 `sum_i D_i`；
2. `Pr(sum_i D_i > Q)` 等联合机会约束；
3. 整体 CVaR、最坏多商品共振；
4. 动态调拨和提前期期间的跨时需求路径；
5. 共同冲击（促销、天气、供应链干扰）的情景风险。

以上“需要/不需要”是损失函数结构判断，而不是对复杂模型的偏好。

### 反例的库存后果（Q=100）

| 分布 | 两个分量的边际 | 总需求 | 共享库存的期望缺货 | 共享库存的期望剩余 |
|---|---|---|---:|---:|
| A 同涨同跌 | 各为 0/100、概率各 1/2 | 0 或 200 | 50 | 50 |
| B 互相错开 | 与 A 完全相同 | 恒定 100 | 0 | 0 |

但在固定分货 `q_X=q_Y=50` 且成本逐项可加时，A 与 B 的 **期望分散缺货量都是 50、期望分散剩余都是 50**。所以不能为了表现联合模型价值而偷偷更换决策场景或损失函数。

## 5. E5 预注册实验：边际分位数是否足够用于库存决策？

### H5-0（负对照）：逐项可加的期望成本
固定所有边际预测、固定订货成本和预算；仅改变商品间依赖结构。
**预期理论结果**：最小期望可加损失不应仅因 Copula 改变而变化。若出现变化，优先检查实现、采样噪声或隐藏约束。

### H5-1（正对照）：共享库存池及联合机会约束
保持同一边际分位数，改变跨区域/跨日依赖；对比共享库存 `Q` 下的：
- `E[(sum D - Q)^+]`
- `Pr(sum D > Q)`
- `CVaR_95(L)`
- 策略所需安全库存和库存成本。

**预期**：至少在构造反例中出现严格差异，真实 M5 数据中的增量是否存在、多少尚未知。

### H5-2：M5 的实际预测质量
以相同可见信息集、同一预测窗口比较：

- B0：逐日边际分位数（经验/Quantile LightGBM）；
- B1：B0 + 无依赖（独立）采样；
- B2：B0 + 残差相关 Bootstrap/秩重排序；
- B3：B0 + 跨时/跨截面概率协调（基于文献方法）。

评分与验证：
1. **边际**：M5 官方九分位点的 WSPL、Pinball，条件覆盖及日跨度分组；
2. **联合**：总量的经验覆盖、Energy Score 与 Variogram Score，按独立预测起点评价；
3. **一致性**：每条情景同时满足商品—区域和日—周—月加和；
4. **决策**：共享库存和分散库存两种场景的成本、服务率、尾部损失；
5. **成本**：训练、推断与场景生成的时间和资源。

### 决策与验收

- G0：纠正提交形状、时间范围、官方九分位点及权重；
- G1：所有模型输出非负、非交叉分位数或明确修复机制；
- G2：概率校准和锐度分开评价；离散计数有质量点时不用生硬的“覆盖恰等于 τ”判定；
- G3：理论正负对照全部成立；
- G4：真实数据使用多个冻结滚动起点、适合依赖的成组 Bootstrap；
- G5：经济价值比较只在**同一库存政策、同成本假设**下进行；另做独立的政策消融；
- G6：若全体与关键分组结果相悖，报告异质性与失败模式，不用总分掩盖。

### 研究结案输出

可接受三种结论：`JOINT_ADDS_VALUE` / `MARGINAL_SUFFICIENT` / `INCONCLUSIVE`。

事前对不同库存政策规定经济收益与风险门槛，不按结果挑选有利阈值。
