02 / M5 DEEP DIVE · UNCERTAINTY SCORING

Uncertainty 竞赛到底如何评估“风险预测”？

明确预测对象

未来 28 天逐日预测（F1–F28）× 42,840 条分层序列 × 九个指定分位数：

0.005 · 0.025 · 0.165 · 0.25 · 0.50 · 0.75 · 0.835 · 0.975 · 0.995

验证期为 d_1914–1941，评价期为 d_1942–1969。每日边际分位数并非 28 天累计分布，也未识别联合依赖。

WSPL：加权尺度化 Pinball

分位点高估、低估按 τ 与 1−τ 不同惩罚，再按序列尺度和销售金额/层级汇总。

既要合理覆盖，也不能用无限宽的区间逃避惩罚。

它优化分位数评分，不是实际的单位缺货/持有成本。

官方提交按 F1–F28 逐日预测；竞赛分位数评分不等于具体库存成本函数。

02 / M5 DEEP DIVE · WHITE-BOX

为什么白盒概率模型能在底层 SKU 赢？

① 状态空间 / 平滑估计时变销售强度与季节因素
② 负二项计数分布表达非负整数、过度离散与频繁零销量

这比“直接训九个分位数”多提供了什么？

  • 对整数计数有显式分布假设
  • 参数少、可解释、计算负担较低

02 / M5 DEEP DIVE · UNCERTAINTY FINDINGS

概率预测的实际结果，比“九个分位数”更复杂

论文报告的积极发现

  • 领先团队的平均概率校准总体较好

03 / VALIDATION

怎么科学评价分位数预测：不是看“区间里面中了几次”

Pinball / Quantile Loss
Lτ(y,q) = { τ(y−q)　若 y≥q
(1−τ)(q−y)　若 y<q }
Pinball 是一致的分位数评分：低估上分位点时通常惩罚更重，但最终也必须检查覆盖率与区间宽度。

建议四类评价同时报告

  1. Pinball / WSPL：与公开 M5 对齐的准确性诊断
  2. 分位数可靠性：P10/P50/P90 的真实覆盖率
  3. 区间宽度 / WIS：限制用过宽区间“保覆盖”
  4. 分组可靠性：城市、品类、头部、长尾与零销量
M5 采用 WSPL 作为竞赛评分；不能直接用 WSPL 代替经济贡献，也不能只看极端 P99.5 的单次是否命中。

APPENDIX / METRIC AUDIT

WRMSSE：权重如何影响模型排名？

单条序列 i
RMSSEᵢ = √ [ mean((y − ŷ)²) / mean(Δy_active²) ]
active history 从首个非零观测开始；预测跨度为 28 天。

层级内加权

每个层级用该层级的销售金额权重汇总序列 RMSSE，层级内权重应归一化。

WRMSSE_level = Σᵢ wᵢ × RMSSEᵢ

12 层级平均

最终总分为 12 个层级分数的平均；每个层级拥有相同的总权重。

WRMSSE = mean(WRMSSE_Level1…12)
WRMSSE 的权重体现销售金额与层级结构，但它仍是预测评分，不是库存成本或利润函数。

APPENDIX / EDGE CASE

WRMSSE 的零尺度边界：不要用 epsilon 掩盖问题

官方规则

排除首个非零销量之前的 leading zeros

RMSSE scale 基于 active history 的一阶差分平方均值，而不是从序列第一天盲目计算。

scale = mean(diff(y_active)²)
实现风险

active scale 仍可能为零或未定义

  • 整个训练历史全零
  • 只有一个 active observation
  • 首个非零后销量恒定

本次检查的 companion R 脚本没有显式 fallback。

正确做法：显式抛出 undefined-scale 状态、记录序列和权重、保持 SCORER_NOT_VERIFIED；禁止加 epsilon、赋零或静默剔除。
